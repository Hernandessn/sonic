# Cronômetro Sonic 🕹️

## Sobre o Projeto
Este projeto é um cronômetro interativo inspirado no universo do Sonic, o famoso ouriço azul dos jogos clássicos. Desenvolvido com **HTML**, **CSS** e **JavaScript**, o cronômetro combina funcionalidades práticas com uma experiência visual divertida, trazendo elementos nostálgicos para os fãs do jogo.

---

## Tecnologias Utilizadas 🛠️

- **HTML**: Estruturação da página e elementos do cronômetro.
- **CSS**: Estilização e animações para criar a atmosfera do jogo.
- **JavaScript**: Lógica do cronômetro e interatividade dos botões.

---

## Funcionalidades Principais 🚀

- **Start**: Ao clicar no botão "Start", o cronômetro começa a contar o tempo, e o Sonic inicia sua corrida animada.
- **Stop**: O botão "Stop" pausa a contagem do tempo e interrompe a animação do Sonic.
- **Restart**: O botão "Restart" redefine o cronômetro para zero e reinicia a animação, permitindo uma nova contagem.

### Detalhes Técnicos
- Utilizei `setInterval` para controlar a contagem do tempo.
- `setTimeout` foi aplicado para criar efeitos temporizados, como transições suaves e animações.
